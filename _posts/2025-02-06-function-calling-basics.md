在函式調用的場景裡，最重要的是讓模型理解「有哪些函式可以用、每個函式需要什麼參數」。文件建議提供 JSON 模式的描述，為每個欄位補上類型、範例與限制條件，讓模型能生成格式正確的呼叫。 

對於回傳結果，範例使用結構化 JSON 或表格文字，並包含狀態碼與錯誤訊息，方便後續流程判斷是否需要重試。若輸入缺失或超出限制，模型應主動回報錯誤而不是盲目執行。 

除此之外，還可以在 prompt 中加入「決策樹」或「選擇理由」的欄位，要求模型解釋為何要呼叫某個函式，這能降低誤用工具的概率，也讓除錯更容易。
